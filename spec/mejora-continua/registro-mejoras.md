# Registro de mejoras

El ciclo es: **planificar** (elegir una mejora) → **hacer** (como cambio controlado) → **verificar**
(mirar el indicador) → **actuar** (dejarla fija o descartarla).

Fuentes de mejoras: incidentes, indicadores fuera de meta, comentarios de usuarios, cierre de cada
fase, revisiones periódicas.

Prioridad: alta, media, baja. Estado: propuesta, en curso, verificando, cerrada, descartada.
